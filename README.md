# 미션 - 다리 건너기

## 기능 구현 목록

1. 게임 시작 메시지 출력
    - “다리 건너기 게임을 시작합니다.”
2. 다리 길이 입력
    - “다리의 길이를 입력해주세요.”
    - 예외 사항
        1. 숫자가 아닌 경우
        2. 3 이상 20 이하의 정수가 아닌 경우
3. 길이에 맞는 다리 생성
4. 이동할 칸 입력
    - “이동할 칸을 선택해주세요. (위: U, 아래: D)”
    - 예외 사항
        1. “U” 또는 “D”이 아닌 경우
    - 다리를 건넌 경우
        1. 결과 출력: 해당 다리 칸에 “O” 표시
        2. 다음 이동할 칸 입력
    - 다리를 건너지 못한 경우
        1. 결과 출력: 해당 다리 칸에 “X” 표시
        2. 게임 재시도 여부 입력
            - “게임을 다시 시도할지 여부를 입력해주세요. (재시도: R, 종료: Q)”
            - 예외 사항
                1. “R” 또는 “Q”이 아닌 경우
        3. "R”이면 시도 횟수 증가 후 4의 처음부터 다시 시작
        4. “Q”이면 최종 게임 결과 출력 후 종료
    - 모든 다리를 건넌 경우
        1. 최종 게임 결과 출력 후 종료

## 체크 항목
1. OutputView의 메서드의 이름은 변경할 수 없다.
2. BridgeGame의 메서드의 이름은 변경할 수 없다.
3. BridgeMaker의 필드(인스턴스 변수)를 변경할 수 없다.
4. BridgeMaker의 메서드의 시그니처(인자, 이름)와 반환 타입은 변경할 수 없다.
5. Random 값 추출은 제공된 bridge.BridgeRandomNumberGenerator의 generate()를 활용한다.
6. BridgeRandomNumberGenerator,BridgeNumberGenerator 클래스의 코드는 변경할 수 없다.
7. BridgeGame 클래스에서 InputView, OutputView를 사용하지 않는다.
